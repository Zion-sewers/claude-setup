# One `path | status` per line. This holds ONLY the residue: documents whose status cannot be
# derived from their class or from a `Status:` line in the document itself. Everything else is
# derived, and adding a row here for a document that declares its own status is a duplication that
# will drift.
#
# The registry started at 37 rows out of 929 tracked markdown files. If it grows much past that,
# the derivation rules are wrong and should be fixed rather than papered over here.
#
# Statuses used, and what each means:
#   living              a document that is continuously edited and has no version. Correct by
#                       construction or it gets fixed; it is never "stale", it is just current.
#   generated           written by a tool. Its truth is the tool's exit code, not a field here.
#   subproject          belongs to intent-control-plane, which has its own docs/ tree and its own
#                       lifecycle. ADR-0017 made claude-setup's copy authoritative.
#   salvage             extracted from something deleted. Frozen by definition; never updated.
#   superseded-by X     a real supersession, with the successor named.
